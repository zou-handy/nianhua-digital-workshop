Technical Implementation

技术实现与项目价值

核心流程

1 输入主题 小程序端收集用户创作需求
2 AI 生图 云函数调用模型生成年画风格图像
3 云端保存 生成图与分色层进入 CloudBase 存储
4 后端分色 输出透明 PNG 色彩图层
5 前端展示 2D 拆解、套印模拟和 3D 展示

后端分色逻辑

项目中最能体现技术实现的部分，是把 AI 生成图继续处理成多个可叠加的色版图层。后端读取图片像素数据，按颜色距离和透明度生成独立 PNG 图层，再将图层上传到云存储，供小程序端按顺序加载。

这样做的价值是：AI 结果不再只是“一张图”，而是可以被拆解为传统木版年画的工艺结构，便于教学展示、交互体验和面试讲解。

黑色：线稿与轮廓
红色：主体红底
黄色：装饰亮色
深黄：文字与厚重色
蓝色：青蓝色块

CI/CD 与资源部署

仓库中配置了 GitHub Actions：当 public/** 资源推送到 main 分支时，自动安装 coscmd，使用 GitHub Secrets 中的腾讯云密钥，将模型、知识图片视频和分层图同步到 COS。

  • public/model/ -> model/
  • public/knowledge/ -> knowledge/
  • public/layers/ -> layers/

小程序端统一使用 CloudBase FileID 引用资源，避免把大视频、大模型和分层图打进主包，预览包体积已控制在约 220KB。

技术栈与模块

小程序前端

原生微信小程序开发，核心页面包括 home、ai-create、exploded-view、model3d-viewer 等。

云函数与 API

CloudBase 云函数负责 AI 生图与分色处理；独立 API 负责 3D 生成任务提交和状态查询。

图像处理

使用像素级处理生成透明 PNG 图层，支持前端逐层叠加和色版交互。

工程治理

处理包体积限制、私有 AppID 配置、密钥隔离、云端静态资源同步和 GitHub 分支发布。

面试说明建议：这个项目可以从“非遗展示”切入，再展开到“AI 生成后的结构化处理”。重点强调你不仅调用了 AI 接口，还把生成结果转成可解释、可交互、可持续部署的产品功能。
